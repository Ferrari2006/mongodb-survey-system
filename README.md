# MongoDB 问卷系统课程项目

数据管理系统课程大作业：使用 MongoDB 实现支持账号、问卷管理、题目校验、条件跳转、答卷提交和统计的问卷系统。

当前状态：需求已初步梳理，项目 skill 已整理；应用尚未实现，尚无运行和测试通过记录。技术框架与详细 Schema 待设计确定。

## 两阶段提交

- 第一阶段：完成初始需求对应的可运行系统、数据库设计、API 和关键逻辑说明、测试用例、AI 使用日志及报告。
- 第二阶段：根据后续需求变更，在第一阶段代码上修改，保留核心结构、旧数据及主要功能，记录兼容性处理和回归测试。
- 两阶段共用本仓库。第一阶段实际验收完成后标记 `stage1-submission`；第二阶段完成后标记 `stage2-submission`，目前尚未创建提交标签。
