# 浏览器验收运行说明

浏览器验收使用Playwright和本机Chrome，不属于应用启动依赖。应用仍只需要requirements.txt中的Python依赖和MongoDB。

## 双账号连续验收

先按README安装Python环境并启动MongoDB。为避免混入正常业务数据，用单独测试库和端口启动应用：

```powershell
$env:MONGO_URI = "mongodb://127.0.0.1:27017/"
$env:MONGO_DB = "survey_test_browser_" + [guid]::NewGuid().ToString("N")
$env:PORT = "5056"
python run.py
```

在另一个终端安装浏览器测试工具并运行：

```powershell
npm install --prefix tmp/browser-runtime --no-save --package-lock=false playwright
$taskPlaywright = (Resolve-Path tmp/browser-runtime/node_modules/playwright).Path
$env:SURVEY_TEST_BASE = "http://127.0.0.1:5056"
node tests/browser_stage2_acceptance.cjs $taskPlaywright
```

脚本建立两个隔离浏览器会话，用合成账号执行页面操作，读取API核对快照和权限效果。成功后生成tests/results/stage2-acceptance.json，截图保存在忽略目录output/playwright。随机测试库不与原业务库混用。

该脚本使用本机Chrome的headless模式；如未安装Chrome，应先安装Chrome或在脚本中改用已安装的Playwright Chromium。完整验收步骤和结果见最终验收-2026-10-28.md。单账号题库检查脚本tests/browser_library.js使用5052端口，与双账号验收分开运行。

## 新环境复现记录

scripts/record_reproduction.py用于记录独立源码启动后的健康检查、依赖和七集合情况。参数--base为服务地址、--mongo为隔离MongoDB连接、--db为survey_test_前缀测试库；连接字符串不写入结果。正式验收使用新venv、Git导出源码、空MongoDB数据目录和独立端口，记录在stage2-reproduction.json。
