# 操作与演示

## 启动

按README安装依赖并启动MongoDB后运行python run.py，访问http://127.0.0.1:5050。本机课程目录可用start.ps1快捷启动。浏览器可自行注册，系统不需要AI API Key。

## 创建与发布

1. 注册账号、登录，点击“新建问卷”。
2. 填标题和说明；选择是否允许匿名、重复填写；可设置本地时区截止时间，留空不限制。保存基本信息。
3. 添加题目：保留自动ID或填稳定ID，选题型、必答及限制。选项每行“ID | 文字”。多选最少最多相同即恰好数量。
4. 配置跳转：选操作，填比较值及后续题ID或END，点击“加入规则”，再“保存题目”。规则按显示顺序匹配，可移除后重新加入调整顺序。
5. 未来目标题可稍后添加；发布前必须存在。发布固定题目与设置，复制分享链接给填写者。

## 填写与提交

1. 填写者打开分享链接，未登录先注册/登录；登录后回到该分享问卷。
2. 点击下一题，后端校验并决定后续路径。留空选答仍要点击下一题。
3. 可返回上一题；修改会清理后续答案，按新路径重新填写。最终确认页可返回修改最后题。
4. 每次点击下一题校验成功后保存已确认进度，刷新或同账号重新登录可继续；当前未确认输入不自动保存。问卷允许时可勾选匿名，该偏好也保存。提交成功后保存正式答卷并清理本次进度，未提交进度不计入统计。
5. 允许重复时再次打开链接可填写新一份；不允许时提交返回重复错误。

## 统计与关闭

创建者在工作台选择“管理问卷”，点击“查看统计与答卷”。可以切换整卷与单题，查看选项计数、填空内容、数字平均值及匿名/实名答卷。计数单位为答卷份数，非去重用户人数。点击关闭后新的填写被拒绝。

## 可复现的演示数据

服务运行后执行python scripts/seed_demo.py。脚本通过真实API生成合成创建者、填写者账号及四题问卷，控制台输出本次用户名、合成密码及链接。它每次生成新账号，不覆盖已有数据。

演示“不使用校园服务”路径会跳过多选和数字必答题，直接填写建议；“使用”路径经过全部题。分数11非法，8合法。分别匿名和实名提交后，创建者看到总数2、单选各1、多选相应计数和数字平均8。

自动化主入口为python tests/run_tests.py。浏览器检查采用Playwright CLI，复现本轮脚本时需按seed输出替换tests/browser_flow.js中的合成账号、密码与URL，并使用空的演示问卷（否则固定期望两份会变化）。这些脚本用于测试，不是后台依赖。
