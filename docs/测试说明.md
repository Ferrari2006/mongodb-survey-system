# 当前里程碑测试说明

运行 `python tests/run_tests.py`，会执行 unittest 并用 Python assert 验证结果，同时生成 tests/results/latest.json。禁止使用 Python -O，否则assert会被移除；记录脚本会拒绝优化模式。

集成测试连接真实MongoDB，自动创建随机 survey_test_ 前缀数据库，并在测试结束时只删除该测试库。不访问此前实验或应用的正常业务数据。TEST_MONGO_URI 可指定测试服务器。测试列表如下；实际执行时间、数量和结果以JSON记录为准。

| 用例方法 | 前置与步骤 | 关键输入 | 预期输出与数据效果 |
|---|---|---|---|
| test_auth_password_and_logout | 注册登录，查询用户，错误登录，重复注册，退出后访问 | 普通用户名、错误密码、同名大写用户名 | 密码为哈希；敏感字段不返回；401、409；退出后401 |
| test_unauthenticated_and_expired | 无令牌访问，随后将测试会话设为过期 | 无认证、过期会话 | 均401，即使TTL尚未清理 |
| test_create_edit_and_owner_isolation | A创建并修改，B查看列表和读写A问卷 | 标题修改、B令牌、伪造owner_id | 创建201、修改200；B列表空、访问404；伪造字段400 |
| test_question_crud_and_preview | 创建问卷、添加数字题、校验、修改、删除 | age范围0～120，120和121，重复题目ID | 120通过、121拒绝；重复ID拒绝；版本递增，删除后数组空 |
| test_invalid_question_does_not_write | 对问卷添加矛盾限制题目 | min=100、max=0 | 400；数据库questions和revision不变 |
| test_optimistic_concurrent_edit | 两个线程用同一revision同时修改 | revision=1，不同标题 | 恰好一个200、另一个409；最终revision=2 |
| test_malformed_requests_and_schema | 非对象JSON、空标题、非法页码、非JSON、破损JSON、直接插入缺字段文档 | 数组、空白、bad、-1等 | 请求400；MongoDB拒绝违反validator的插入 |
| test_number_boundaries | 纯函数校验年龄 | 0、120、18、-1、121、小数、布尔值、NaN、无穷大、巨大整数 | 边界合法；其余非法值抛DomainError |
| test_text_limits | 纯函数校验2～4字符 | 两字、过短、过长、空白、数字 | 合法字符串通过，其余拒绝 |
| test_selection_constraints | 单选和恰选两项多选 | 合法组合、缺项、超量、重复、未知选项 | 正确组合通过，非法组合拒绝 |
| test_optional_empty | 选填文本且非空至少两字符 | 空、单字符、数组、对象、布尔值 | 空返回None；其余非法值拒绝 |
| test_invalid_question_definitions | 创建错误定义 | 颠倒边界、重复选项、不支持字段、错误required类型 | 定义阶段拒绝 |
