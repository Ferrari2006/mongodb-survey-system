# 分层图示来源与含义

本轮参考用户截图中的浅色分区、层次关系及圆柱集合造型，重新绘制本项目的架构与五集合图。没有复制参考项目的Vue、TypeScript、版本快照或事务能力。

- 架构图事实来源：backend/app.py的Flask接口、Bearer会话认证和权限检查；backend/logic.py、validation.py；statistics.py；database.py。
- 数据关系事实来源：surveys.questions嵌入题目配置；sessions、surveys、fill_progress、responses通过字符串ID引用。进度和答卷分别保存，不声称存在数据库外键。
- 数据访问框表示PyMongo的调用方式，不是另行部署的微服务。图中实线表示请求/访问，虚线表示模块协作。
- 统计图仅从图2改编号为图3，原始数据、图形编码和统计口径不变。

图源在reports/images/stage1-architecture-layered.svg、stage1-data-model-layered.svg；scripts/draw_layered_architecture.py可重绘。保留对应PNG给Word使用，报告HTML嵌入SVG。架构关系另提供.mmd便于编辑，不把它称作已用Mermaid渲染出的成图。
