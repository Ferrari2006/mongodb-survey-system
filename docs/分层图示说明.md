# 分层图示来源与含义

本文说明第一阶段架构图与五集合图的含义。图中模块、认证方式和数据关系对应第一阶段Flask与PyMongo实现；第二阶段新增结构见第二阶段/images目录。

- 架构图事实来源：backend/app.py的Flask接口、Bearer会话认证和权限检查；backend/logic.py、validation.py；statistics.py；database.py。
- 数据关系事实来源：surveys.questions嵌入题目配置；sessions、surveys、fill_progress、responses通过字符串ID引用。进度和答卷分别保存，不声称存在数据库外键。
- 数据访问框表示PyMongo的调用方式，表示应用内的数据访问层。图中实线表示请求/访问，虚线表示模块协作。
- 统计图仅从图2改编号为图3，原始数据、图形编码和统计口径不变。

图源在reports/images/stage1-architecture-layered.svg、stage1-data-model-layered.svg；scripts/draw_layered_architecture.py可重绘。保留对应PNG给Word使用，报告HTML嵌入SVG。架构关系另提供.mmd便于编辑，实际报告成图由SVG代码绘制。
