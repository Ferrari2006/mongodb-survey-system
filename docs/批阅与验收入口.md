## 启动前只读检查

安装依赖、配置环境变量并启动MongoDB后，在仓库根目录执行：

```powershell
python scripts/check_environment.py
```

该脚本检查Python、锁定的两个直接依赖、必要文件、端口配置与MongoDB ping。不创建集合、不迁移、不读取答卷，也不输出连接URI或密码。它只确认启动前的有限条件，不代替API测试、数据库读写权限检查或业务测试。

尚未启动MongoDB时可执行 `python scripts/check_environment.py --skip-mongo`。输出会明确标为`not_checked`，不能将该结果称作数据库已连通。脚本读取进程环境变量，和应用一样不自动读取.env。

## 关键验收结果应是什么

1. 跳转跳过的必答题不会阻止提交；提交夹带路径外答案会被拒绝。
2. 返回改答后重新形成有效路径，未确认输入不自动保存；进度本身不进入统计。
3. 同一request_id重试不会新增答卷；关闭后拒绝新提交，已成功请求的重试返回原回执。
4. 匿名答卷对创建者隐藏身份，后端仍保留内部身份用于权限和防重。
5. 统计分母是该题有效答卷份数，多选比例可超过100%；数字0有效，空答不算0。

以上场景对应基础测试和演示步骤。check_submission.py用于第一阶段提交快照的材料检查；当前工作树使用check_stage2.py。题库和多版本属于第二阶段扩展，单独记录验收结果；系统未使用跨集合事务。
